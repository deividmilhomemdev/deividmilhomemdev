- 💡 **Diferencial:** Traduzo desafios complexos de negócio em soluções técnicas enxutas — do banco de dados ao front-end/mobile.
- 🌱 **Estudando:** Engenharia de Dados (Alura), testes automatizados e pipelines CI/CD.
